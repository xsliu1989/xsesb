- **【已实现】**：代码中存在可运行的完整实现。

- **【未实现】**：代码中仅存在注释、空模块或字段定义，没有实际逻辑。

## 3. 一句话定位

> 以交易码为路由键、以数据库元数据（Tag 表）驱动报文双向转换、接入 HTTP/TCP、出站 HTTP/TCP，并配套过滤器链、双缓存、国密加解密与交易日志的**配置化轻量级 ESB / 协议转换网关**。

## 4. 核心术语

| 术语 | 含义 |
|---|---|
| 渠道 / 源系统 / Customer | 请求发起方，如外部渠道、客户端系统 |
| 第三方 / 目标系统 / Provider | 被 ESB 调用的后端系统 |
| 交易码 / `tranNo` | 接口唯一编号，是路由、映射、限流、日志的主键 |
| Tag / 标签 | 描述报文一个节点的元数据，含父子路径、取值路径、类型、长度、排序 |
| 四段式映射 | 渠道请求 String → Map → 渠道请求模型 → 第三方请求模型 → String，返回逆向执行 |
| 双缓存 | `cache.cacheName=map` 使用本地静态 Map；`=redis` 使用 Redis Hash 存储序列化对象 |
| 定长 / DC | 报文字段无分隔符，按 Tag 中配置的字节/字符长度和顺序切分与拼接 |
| cPort | TCP 出站目标地址映射文件 `cPort.json` |
| serid | 单次请求链路号，写入 MDC 与交易日志 |
